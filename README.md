🗼 Tower of Hanoi Visualizer

An interactive web application that visualizes the classic Tower of Hanoi puzzle using recursion with real-time animation.

🌟 Features
- Adjustable number of disks (3 to 8)
- Customizable animation speed
- Real-time step-by-step visualization of recursive solution
- Shows total moves required (2ⁿ - 1)
- Clean and educational interface

🛠️ Tech Stack
- Python
- Streamlit
- Recursive Algorithm

🚀 How to Run Locally
```bash
git clone https://github.com/simplyme429/tower-hanoi-visualizer.git
cd tower-hanoi-visualizer
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
